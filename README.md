# humanagentcontrol.com

**How does a human stay in control when agents are faster than they are?**

A manifesto by Samuel Fleig — eight principles for staying in charge of your own attention and judgment when the agents you run outpace you. Not AI safety, not compliance: one person and their mind.

- `public/index.html` — the site: an interactive hourglass. Single file, no external resources, light/dark.
- Deployed as a Cloudflare Worker with static assets (`wrangler.jsonc`).

Status: early version, not indexed yet.
